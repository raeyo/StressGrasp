## 1. 검증하려는 컨셉

사용자 제안 (2026-09-29): *"접근 후 xyz 6축 외력을 주고, 버틴 축 수(0~6)를 최종 점수로 쓴다.
이걸 RL 보상이 아니라 **학습 데이터 라벨**로 쓰고 (BODex/DexGraspNet 계열 검증 관행),
critic 은 현재 상태에서 간접적으로 force closure / GWS 를 체크하는 네트워크 역할을 한다."*

이 컨셉이 성립하려면 **세 고리가 모두** 참이어야 한다.

| 고리 | 명제 | 게이트 |
|---|---|---|
| ① 라벨이 물건인가 | 같은 (물체·장면·자세)를 다시 재면 같은 카운트가 나오는가 | **G-A** |
| ② 상태에서 예측되는가 | 장면+자세를 보는 네트워크가 카운트를 맞히는가 | **G-B** |
| ③ 예측이 쓸모있는가 | 그 예측으로 후보를 고르면 실제로 더 버티는가 | **G-C** |

**하나라도 깨지면 컨셉은 그 지점에서 기각**하고, 다음 고리는 재지 않는다.

## 2. 왜 이 형태인가 (선행 null 과의 관계)

[`RESULTS_RESIDUAL.md`](RESULTS_RESIDUAL.md) §10-2 가 잰 것: 마진 여유는 **장면(초기자세) 조건부**로
실재한다 (고정 장면 +0.111, 물체 수준 고정 edit 의 전이 ≈0). 장면 조건부 여유를 쓰려면
**장면을 보고 판정하는 함수**가 필요하다 — 그게 여기서 말하는 critic 이다.
선행 실패의 입력(특권 55-d, 형상 없음)으로는 원리적으로 불가능했다. 그래서 §6 의 입력 변형에서
**55-d 단독(V1) 과 형상 포함(V2) 을 나란히 놓는 것이 이 실험의 핵심 대조**다.

★ 보상 스케일을 0~6 으로 바꾸는 것 자체는 새롭지 않다 — 기존 `bsum`(= 카운트/6)과 동일하고
PPO 는 advantage 를 정규화하므로 구별되지 않는다. **새로운 것은 "보상이 아니라 라벨"이라는 전환**이다.

## 3. 라벨 정의 (고정)

기존 측정 장치를 그대로 쓴다: palm 좌표계 · ±xyz 6방향 · α=1 g(303 mN) · 분기 지평 H=5 env-step ·
이진 hold `1[d_i < θ]`, θ=20 mm. α=1 g 는 [`EXP_RESIDUAL.md`](EXP_RESIDUAL.md) §7 에서
**Δ=0 으로 보정**한 값이다 (네 방향이 0.46~0.60 = 베르누이 분산 최대).

- **1차 라벨 = grip 구간 전 window 평균 카운트 (0~6)**. 기존 모든 수치(Δ=0 대조군 "6방향 합
  3.240")와 같은 양이라 연속성이 있다.
- **2차 라벨 = 첫 window 단독 카운트** (= 사용자 제안의 "접근 후 1회 프로브" 형태).
  둘 다 덤프하되 **판정은 1차로 한다.** 2차는 "1회 프로브로도 되는가"를 별도 보고.
- lift 실패 후보도 **카운트를 그대로 기록**한다 (제외하지 않는다). lift SR 은 병기해 비퇴화를 본다.

## 4. 데이터 생성 (고정)

- 물체셋 `ours_bench/ours_S.yaml` (33), teacher `inspire.pt`, episodeLength 50.
- **장면** = 에피소드마다 물체별로 새로 뽑은 초기 자세. 한 에피소드 안에서는 전 후보가 **같은 장면**.
- **후보** = teacher 의 t=0 12-D edit 에 `σ·N(0,1)` 을 더하고 [-1,1] 클램프.
  물체당 R=8 후보: **후보 0 = teacher 원본**, 나머지 7 은 σ ∈ {0.15, 0.35, 0.6} 를 순환.
  (12-D 의 물리 스케일 = 손목 ±5 cm · 손목 RPY ±1.57 rad · grasp qpos ±1 rad)
- ★ **모든 후보를 2회 독립 측정한다** (repeat A/B: 같은 장면·같은 plan, DOF reset 노이즈만 다름).
  → ① G-A 의 재현성, ② G-C 의 **편향 없는** 선택 평가(A 로 고르고 B 로 읽는다)를 동시에 얻는다.
  이것은 [`RESULTS_RESIDUAL.md`](RESULTS_RESIDUAL.md) §10 의 교훈(best-of-N 보고값은 상한이 아니다)의 직접 적용이다.
- **물체 split**: `obj_id % 4 == 3` → **test(홀드아웃)**, 나머지 → train. 학습은 test 물체를 한 번도 보지 않는다.

## 5. G-A — 라벨 재현성 (고리 ①)

repeat A/B 쌍으로 계산한다.

| 지표 | 기준 |
|---|---|
| 같은 (장면·자세) 반복의 카운트 차 표준편차 `σ_label` | **≤ 1.0 카운트** |
| 급내상관 `ICC = (σ²_between − σ²_label/2) / σ²_between` (후보 간 분산 중 재현되는 비율) | **≥ 0.5** |

**불통과 시**: 라벨이 잡음 반이라 어떤 네트워크도 못 배운다 → **컨셉 기각, §6·§7 는 재지 않는다.**
(대안 = 라벨당 반복 측정 수를 늘리거나 α·θ 를 재보정)

★ ICC 는 G-B 의 **달성 가능 상한**을 정한다 (완벽한 예측기도 ρ ≤ √ICC). 그래서 G-B 는
절대값과 함께 `ρ/√ICC` 를 병기한다.

## 6. G-B — 상태에서 예측되는가 (고리 ②)

**홀드아웃 물체**에서, critic 예측 vs 실제 카운트(A/B 평균)의 Spearman ρ.

입력 변형 (같은 데이터, 학습만 다시):

| 변형 | 입력 | 역할 |
|---|---|---|
| **B0** | 물체 id one-hot 만 | 하한선 — "물체만 알면 이만큼 맞힌다" |
| **V1** | 특권 55-d (= 선행 residual 의 입력) | 선행 실패 조건의 재현 |
| **V2** | 55-d + palm 좌표계 PCL 256점 | ★ 본안 — 장면 기하를 준다 |
| **V3** | PCL 256점 단독 | 기하만으로 되는가 |
| **V4** | 55-d + 후보 12-D plan | 결과 상태 외에 계획을 아는 게 도움이 되는가 |

| 관문 | 기준 |
|---|---|
| **G-B1 절대** | `ρ(V2) ≥ 0.4` (홀드아웃 물체) |
| **G-B2 기하 기여** | `ρ(V2) − ρ(V1) ≥ 0.10` |
| **G-B3 물체 암기 아님** | `ρ(V2) − ρ(B0) ≥ 0.10` |

**불통과 시**: 카운트는 이 상태 표현에서 예측되지 않는다 → **critic 노선 기각**,
§7 은 재지 않는다. (B1·B2 만 깨지고 B3 는 통과 = "물체 정체성만 학습" → 표현 문제로 보고)

## 7. G-C — 선택 이득 (고리 ③)

홀드아웃 물체·장면에서, 장면당 R=8 후보 중 하나를 고른다. **repeat A 의 특징으로 고르고,
repeat B 의 측정값으로 읽는다** (선택과 평가를 분리 — max-selection bias 차단).

| 선택 규칙 | 의미 |
|---|---|
| `teacher` | 후보 0 (무개입 기준선) |
| `random` | 8개 중 무작위 1개 (기대값 = 후보 평균) |
| **`critic`** | V2 예측 argmax |
| `oracleA→B` | A 측정 argmax → B 로 읽음 (편향 없는 도달 상한) |

| 관문 | 기준 |
|---|---|
| **G-C1 이득** | `critic − random ≥ +0.15 카운트`, 장면 단위 페어드 부트스트랩 95% CI 가 0 을 제외 |
| **G-C2 비퇴화** | critic 선택의 lift SR ≥ random 의 lift SR − 0.05 |
| **G-C3 효율** | `η = (critic − random) / (oracleA→B − random)` 을 병기 (판정 아님, 보고) |

**+0.15 의 근거** (이 데이터를 보기 전에 선행 수치에서 유도): [`RESULTS_RESIDUAL.md`](RESULTS_RESIDUAL.md)
§10-2 의 **정직한 고정 장면 오라클 갭 = +0.111 (fraction) = +0.67 카운트**. 그건 물체당 ~80개
CEM 후보를 쓴 값이고 여기는 8개 무작위 후보이므로, 그 **25%** 를 목표로 잡아 +0.17 → 보수적으로
**+0.15** 로 고정한다. (EXP_RESIDUAL §8-3 의 "오라클 갭의 25%" 관례 승계)

**불통과 시**: 예측은 되지만 선택으로 이득이 안 난다 → 후보 분포(σ) 또는 라벨 상한의 문제로
기록하고, 후보 생성 방식을 바꿔 재측정 (임계는 바꾸지 않는다).

## 8. 병기 필수

- 카운트 분포 · 방향별 hold 6개 (기존 표와 같은 형식)
- 1차(전 window 평균) vs 2차(첫 window) 라벨의 ICC·ρ 비교 → "접근 후 1회 프로브로 충분한가"
- σ 수준별(0.15/0.35/0.6) 카운트·lift SR — 후보 분포가 어디서 무너지는가
- 학습 곡선 및 홀드아웃 손실 (과적합 여부)

## 9. 이 실험이 말하지 **않는** 것

- 해석적 GWS(ε-metric / Q1) 와의 비교는 **이번 범위 밖**이다 (구현 시간). G-B 통과 시 다음 라운드.
- 토크·모멘트 저항 미측정 (force 3축만) — 평가 홀드아웃 축으로 남겨 둔다.
- teacher `inspire.pt` · Inspire RH56 · `ours_S` 한 조합. 다른 손·물체셋은 모른다.
- 정책 학습은 하지 않는다. 여기서 검증하는 것은 **라벨·예측·선택**까지다.

## 11. ★ 스모크 기반 설계 변경 (2026-09-29, 판정 전 · 임계값 불변)

2 에피소드 스모크(n=528)로 **하네스 정합성과 후보 분포만** 확인한 뒤 아래 셋을 바꿨다.
**§5~§7 의 게이트 임계값은 하나도 바꾸지 않았다** — 바꾼 것은 실험 조건이다
(EXP_BRANCH §3 의 "임계가 아니라 실험 조건을 바꾼다" 규율 승계).

**정합성 확인 (바꾸지 않음)**: 슬롯 0(teacher 원본)이 `카운트 3.162 · lift SR 0.712` 로
기존 Δ=0 대조군(`6방향 합 3.240 · SR 0.755`)을 재현했다. 라벨 장치가 선행 측정과 같은 양을 잰다.

| # | 바꾼 것 | 왜 |
|---|---|---|
| 1 | 후보 σ **{0.15, 0.35, 0.6} → {0.05, 0.10, 0.20}** | σ=0.35 에서 lift SR 0.144, σ=0.6 에서 0.038 로 붕괴. 후보의 7/8 이 들지도 못하면 §7 의 선택 실험이 "실패 중 고르기"가 된다. 정직한 오라클 갭(+0.111)이 관측된 영역도 teacher 근방이다 |
| 2 | 독립 반복 측정 **2회 → 3회 (A/B/C)** | 스모크의 1회 측정 재현성이 `corr(A,B)=0.518` 로 G-A 경계선. 학습 라벨은 3회 평균을 써서 신뢰도를 올리고(Spearman-Brown), **G-A 판정은 규정대로 1회 측정 ICC 로** 한다 |
| 3 | 규칙 추가: **`nwin == 0` 후보는 분석에서 제외** | grip 에 한 번도 진입 못 한 후보(스모크 7%)는 라벨이 정의되지 않는다. 제외 비율을 반드시 병기한다 |

★ 1 은 G-C 를 **쉽게 만드는 방향이 아니다** — 후보가 teacher 에 가까워지면 후보 간 카운트 차가
줄어 `critic − random` 도 같이 줄어든다. G-C1(+0.15)은 그대로 둔다.

### 역할 분담 (데이터 누수 방지)
- **A** = critic 입력 특징 + §7 의 선택 · **B** = §7 의 평가(읽기 전용) · **C** = 보고용 3번째 측정
- 학습 라벨(train 물체) = mean(A,B,C) · 홀드아웃 물체는 학습에 일절 쓰지 않는다
