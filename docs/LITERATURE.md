## 0. ★ 감시 결과 — 우리 지표에 선행이 있다

`Stability_Metrics.md` §8 이 정리한 선행(RobustDexGrasp 2.5 N · BODex 6방향 전부 통과 ·
DexGraspNet 6방향 중력 · Grasp-to-Act 12방향 ramp · Whole-Hand Force Regulation)에 **한 건을 더한다.**

| # | 사실 | 수치 | 등급 |
|---|---|---|---|
| **L1** ★ | **D3Grasp** 는 성공을 `s_grasp`(접촉) · `s_lift`(0.1 m) · **`s_disturb`(외란 저항)** 셋으로 **이미 분리**한다 | 리프트 후 **2.5 N × 6축 × 2 s**, 변위 **0.02 m** 초과 시 실패. 실기 50물체 90.5% | **[원문]** [2509.19892](https://arxiv.org/abs/2509.19892) (2025-09) |
| **L2** | 6방향 외력 프로토콜의 관측된 변형 — 크기는 **물체 무게의 분수**, 지속 **1~2 s**, 판정 **변위 2 cm** | `0.1·mg × 1 s × 6방향` · `0.5·mg × 6축` (단일축 성공 / 6축 전부 성공 구분 표기도 있다) | **[2차]** — **원문 대조 전 인용 금지** |
| **L3** | shaking test 계열 = "들고 10 초 버티면 성공", 외력 12~15 N 규모 | | **[2차]** |

> ★ **L1 은 `Stability_Metrics.md` §8 표에 없다** — 이 감시의 실제 수확이다.
> **정책 학습 계열도 2025 년부터는 6방향 외란 테스트를 쓴다.** 따라서:
>
> - **"지표를 새로 제안했다"를 기여로 쓸 수 없다.** 6방향 흔들기는 데이터셋 라벨링에서 이미 표준이고
>   (DexGraspNet·ACRONYM), 정책 평가에도 들어왔다.
> - ⚠ 우리 라벨 파라미터(`α=1 g=303 mN · θ=20 mm · 6방향`)까지 **관행과 같은 자리**에 있다 —
>   **독립 도달이지 신규 제안이 아니다.**
> - ★ 단 `Stability_Metrics.md` §8 의 각주가 방어선을 준다: *"DexGraspNet 의 학습 모델 평가에는
>   **6방향 중 하나만 버텨도 성공**으로 보는 완화된 기준이 사용된다. '6방향을 시험했다'는 설명만으로
>   BODex 의 **모든 방향 통과** 조건과 같은 것으로 간주하지 않는다."*
>   → **"모든 방향 전부 통과(R_all)"를 정책 평가에 쓰는 것**은 여전히 드물다.

## 1. 그래서 우리에게 남는 기여 후보

| 후보 | 상태 |
|---|---|
| **파지 후 `R_all` 로 재면 universal 정책이 약하다** (결정 1, [`FACTS.md`](FACTS.md) A4) | ★ 가장 방어 가능. 선행은 단일 힘·완화 기준을 썼다 |
| **낙하 없는 자세 변화가 유지보다 .1~.2 낮다** (A4-2) | 지표 C 계열. `Stability_Metrics.md` §5 가 정의를 이미 갖췄다 |
| **형성 단계의 이방성**(A1, 60~80배) + **기제**(엄지 홀로 대립, URDF) | 형성 단계를 6방향으로 잰 선행을 아직 못 찾았다 (→ G1) |
| 라벨 **신뢰도 분석** (1회 ICC .554 / 3회 .789) | 선례 못 찾음. ⚠ 출처가 미merge 브랜치(`kimm/critic`) |
| **lift SR ↔ 안정성 순위 역전** (A2) | ⚠ **이중으로 약해졌다** — 근거 수치가 인용 보류(A2 경고) + 파지 후 미재현(A4-3) |
| **개입이 막히는 지점의 분해** (C1~C3, B3) | 부정 결과의 진단. steering 계열(§3)에 같은 분해를 못 찾았다 |

## 2. 해석적 품질 지표 — 우리가 "해석 안 함"을 택한 근거 **[2차]**

정의·계보는 [`Stability_Metrics.md`](Stability_Metrics.md) §7(Ferrari–Canny Q1 / ε · 마찰 원뿔 여유)이 정본.
여기는 **방법 선택의 근거**만 감시한다.

| # | 사실 | 등급 |
|---|---|---|
| **L4** | ★ **ε·힘 닫힘이 실제 성공을 잘 예측 못 한다는 보고** (Balasubramanian 2012 · Goins 2014), 마찰·접촉점 **mm 오차에 민감**(Weisz & Allen 2012). 커뮤니티가 경험적 성공으로 옮기고 **가장 싼 것이 lift 였다** | **[2차]** → **G2** |
| **L5** | **미분 가능한 Q1 변형**이 존재해 손이 물체에 닿지 않은 상태까지 일반화하고 신경망이 end-to-end 로 예측한다 | **[2차]** |

> ⚠ **L4 가 [2차] 등급인 채로 "해석 안 함"을 논문에 쓰면 근거가 빈다.** 원문 대조가 필요하다.

## 3. 검증기 재순위(steering) 계보 — 우리 critic 노선의 위치 **[2차]**

| # | 사실 |
|---|---|
| **L6** | **V-GPS** ([2410.13816](https://arxiv.org/abs/2410.13816)) — 오프라인 RL value function 으로 generalist 정책의 행동 후보를 **배포 시점에 재순위**. 가중치 접근·파인튜닝 없이 plug-and-play |
| **L7** | 같은 계열이 빠르게 늘고 있다 — VLM 검증기 generator-verifier · value-guided denoising(FM-Steer, CVPR 2026) · **verifier-free** test-time sampling(2510.05681) · runtime monitor 형 |

> ★ 우리 critic 재순위는 이 계보와 같은 메커니즘이고, 결과는 **부정 결과의 진단**이다 —
> *검증기가 잘 작동해도(η=.52) **후보 풀에 teacher 를 넘는 것이 없으면 소용없다**.*
> ⚠ 출처가 미merge 브랜치(`kimm/critic`)다.

## 4. lift 모션 구현 4계열 **[사용자]**

1. 손목/베이스 z 등속 증가 — GraspGF · GraspXL
2. 팔 관절 고정 자세 보간 — RobustDexGrasp · SeqDex
3. 상방 힘 인가 — GraspGF 변형
4. **데모 궤적 lift 구간 재생** — ★ **DemoGrasp** (22프레임 중 13프레임부터)

> 공통점: **방향은 예외 없이 월드 +z 고정, 손가락 폐합 동결, 등속.**
> ★ 우리가 쓰는 것은 4번이고, 이 구조가 [`FACTS.md`](FACTS.md) **A5**(`F1`)의 기계적 원인이다 —
> 레퍼런스가 끝나면 관절 목표가 고정되고 PD 가 물체를 **케이지에 가둔다.**

## 5. ★ 공백 — 여기 없는 것을 "없다"고 말하지 마라

| # | 공백 | 왜 급한가 |
|---|---|---|
| **G1** 🔴 | **형성 단계(grip 중)를 6방향으로 잰 선행이 있는가** | A1 의 신규성이 여기서 갈린다. `Stability_Metrics.md` §8 의 선행은 전부 **파지 후**다 |
| **G2** 🔴 | **L4 의 원문 대조** (Balasubramanian 2012 · Goins 2014 · Weisz & Allen 2012) | **"해석 안 함, 경험적 ε" 이라는 방법 선택의 근거** |
| **G3** 🟡 | **lift SR ↔ 외란 저항 상관을 문헌이 이미 보고했는가** | A2 가 이미 두 번 약해졌다. 걸리면 완전히 잃는다 |
| **G4** 🟡 | **L2 의 원문 대조** — 어느 논문이 정확히 어떤 6방향 파라미터를 쓰는가 | 우리 라벨 파라미터의 선행 여부 |
| **G5** 🟢 | **촉각으로 파지 안정성을 예측**한 선행 (taxel 유무별, net-force-only 가 되는가) | 촉각 라인의 성패를 좌우 |
| **G6** 🟢 | **중단·재계획**(regrasp) 문헌 — 언제 포기하고 다시 잡는가 | 닫힌 고리 라인의 선행 |
