## P0. ★ 최상위 규율 — 판정 임계는 **수치를 보기 전에** 고정한다

**실험 조건은 바꿔도 되고, 임계는 못 바꾼다. 게이트 실패는 그대로 기록한다.**
실제로 critic 실험에서 임계 +0.15 가 사후에 보니 과했다는 것이 드러났지만
**바꾸지 않고 불통과로 기록**했다 ([`EXPERIMENTS.md`](EXPERIMENTS.md) E9). 이 규율이 이 프로젝트의 모든 수치를 지탱한다.

## 2. 두 개의 메타 교훈

> **교훈 1 (P1·P2·P10)**: **강도를 바꿔도 효과가 평평하면, 효과가 없는 게 아니라 계측기를 의심한다.**
> 이 프로젝트에서 세 번 일어났고 세 번 다 계측기였다.

> **교훈 2 (P6)**: **오차가 상수이고 그 값이 설정 파일의 어떤 값과 정확히 일치하면,
> 물리가 아니라 좌표계를 의심한다.**
> 원인을 가른 방법 = 변위의 수직/수평 성분 분해 + 성분 ablation
> (dof만 = 정상 · 무동작 push = 정상 · 제자리 +1 mm = 정상 · **수평 이동 = 낙하**).

## 3. null 이 나왔을 때의 체크리스트

순서대로 묻는다. 위 셋에서 걸리면 **결론을 쓰지 마라.**

1. **관측 채널이 실제로 0 이 아닌가** (P7) — 입력에 답이 없으면 모델을 의심할 수 없다
2. **게이트가 이 행동 공간에서 도달 가능한가** (P4) — sweep 으로 가동범위부터 잰다
3. **대조군이 같은 코드 경로인가** (P5)
4. 강도를 바꾸면 효과가 움직이는가 (P1·P2·P10)
5. 상한이라고 부른 값을 **독립 재생으로 검증**했는가 (P3)
6. 행동 공간을 실제로 다 썼는가 (포화도 — 실측 .30~.44 였다)

★ **실제 이력**: E4~E6 의 null 은 **1·2·6 에서 걸렸다.** 그걸 모르고 "residual 로는 안 된다"를
두 번 썼다가 두 번 정정했다 ([`EXPERIMENTS.md`](EXPERIMENTS.md) §1).

★ 그리고 **게이트가 통과해도 지표가 순환적이면 무의미하다** — 분기 실험의 AUC 게이트가 그랬다
([`FACTS.md`](FACTS.md) D4).
