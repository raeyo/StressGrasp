## 1. 유효 실험

| # | 실험 | 게이트 결과 | 한 줄 판정 |
|---|---|---|---|
| **E1** | **Stage 0 낙폭** (유지시간·질량·파지후 외력) | 위생 전부 통과 · **F1 발동** | 조작 현실 범위에서 **낙폭 없음**(ΔSR +0.020) → v1 문제 종료 ([`PROBLEM.md`](PROBLEM.md) §6) |
| **E2** | **실패 조건 지도** (시점 3분할 × 강도) | 해당 없음 (판정 안 함) | ★ **형성 중이 파지 후보다 3배 아프다** → 축 전환의 계기 |
| **E3** | **분기 마진 M(s) 측정** | **충실도 통과**(78 µm, 불일치 4.9~7%) · **본 게이트 통과** | ★ **반쪽 케이지 확정**(60~80배) + **lift SR ↔ 마진 순위 역전** |
| **E4** | residual RL — **grip 중, 연속 보상** (MIN/SUM) | G1 ✅ · **G2 ❌ G3 ❌** · G4 구별불가 | **null** |
| **E5** | residual RL — **t=0 계획** (plan MIN/SUM, ±0.2) | G1 ✅ · **G2 ❌ G3 ❌** | **null**. 6방향 합이 오히려 감소(2.755→2.463) |
| **E6** | residual RL — **이진 보상**(원안 복원) | **G2 ❌ G3 ❌** | **null**. 진단은 맞았으나 결과 동일 — **보상 형태는 구속 조건이 아니었다** |
| **E7** | **Δ 민감도 감사** (`sweep`, 사후) | 해당 없음 | ★ **E4~E6 이 설계 에러였음을 확정** — 가동범위 전체 **0.012** < 게이트 +0.10 |
| **E8** | **오라클 상한 CEM + 독립 재생 검증** (게이트 재등록 후 재실험) | **G1′~G3′ ❌** | ★ **CEM 보고값이 상한이 아니었다**(편향 .17). 정직한 상한 = 고정장면 **+0.111**, 전이 **≈0** |
| **E9** | **버팀 카운트 critic** (3고리) | **G-A ✅ G-B ✅ G-C ❌** | 라벨·예측 통과, **선택 불통과**. 병목은 critic 이 아니라 **후보 풀** |
| **E10** | **촉각 채널 감사** (사후) | 해당 없음 | ★ **접촉력 18-d 가 E4~E9 전부에서 상수 0** 이었다 |

### 통계
- **게이트를 통과한 개입: 0건** (E4·E5·E6·E8·E9 G-C 전부 불통과)
- **게이트를 통과한 측정: 3건** (E1 위생 · E3 · E9 G-A/G-B)
> **재는 데는 성공했고, 바꾸는 데는 아직 한 번도 성공하지 못했다.**

### 사후 정정 이력 — 지우지 않는다 (**검산이 작동한 흔적**)
| 순서 | 무엇을 뒤집었나 |
|---|---|
| 1차 | E4~E6 의 null 은 "효과 없음"이 아니라 **검정력 부족**이었다 (→ P4) |
| 2차 | **오라클 상한 자체가 부풀려져 있었다** (CEM max-selection bias, → P3) |
| 3차 | **촉각 채널이 전 실험에서 죽어 있었다** (→ P7) |
| — | **가짜 양성 1건 차단** — 평가 코드 경로 차이가 M +0.10 으로 둔갑했다 (→ P5) |

### 사전등록 게이트 중 **무의미했던 것** (정직성)
분기 실험의 "M → 최종 성공 AUC ≥ 0.65" 게이트는 통과했으나(AUC .92~.95)
**그 지표가 순환적**이라 무의미했다 ([`FACTS.md`](FACTS.md) D4). **인용 금지.**
