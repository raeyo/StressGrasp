## 2. 무엇이 실패했고, **왜** 실패했나 (사후 방법론 검토)

residual RL 6변형이 전부 null 이었다 ([`RESULTS_RESIDUAL`](RESULTS_RESIDUAL.md)). 원인을
입력·출력·학습으로 분해하면 아래와 같다. **이 절이 다음 설계의 근거다.**

### 2-1. 출력 — 실패 기제와 축이 어긋나 있었다
- grip 변형의 행동은 `[EE 위치 3, 손 관절 6]` 이고 **손목 회전(ref action 3:6)은 한 번도 건드리지
  않았다** (`gs_residual.py` 의 주입은 `act[:,0:3]` 과 `act[:,hand_dof_start_idx:]` 뿐).
  그런데 오라클 해가 주로 바꾸는 것은 **손목 회전(.14~.25)과 손 관절**, 위치는 가장 적게(.06~.19)다.
  **가장 덜 중요한 축만 주고 중요한 축은 안 줬다.**
- 더 근본적으로 Inspire RH56 의 active 6-DoF 는
  `little_1 · ring_1 · middle_1 · index_1 · thumb_2 · thumb_1` 로 **네 손가락에 외전(spread)이 없다.**
  −x 쪽에 닫힘을 만들 수 있는 자유도는 **엄지 회전 + 손목 자세**뿐이다.
  → 세 번 재현된 서명 **"원뿔은 회전할 뿐 커지지 않는다"** 는 이 하드웨어 제약의 직접적 귀결로 보인다.
- 그리고 학습이 쓴 공간(±1 cm·grip 한정)의 **마진 가동범위 전체가 0.012** 였다 (게이트는 +0.10).

### 2-2. 입력 — 보상이 관측의 함수가 아니었다
- grip 변형의 관측에 **물체 형상이 없다.** M6 이 이것을 직접 확인했다 (ρ .184 vs .457).
- **★ 접촉력 18차원은 상수 0 이었다** — `contact_collection: 0` (CC_NEVER).
  즉 **촉각 정보를 하나도 보지 못한 채** 학습했다 ([`RESULTS_CRITIC`](RESULTS_CRITIC.md) §0-1, 계측기 결함 #7).
- 직전 프로브 결과도 관측에 없다. **정책은 자기가 최적화하는 양을 한 번도 보지 못한다.**
  → value 가 못 맞추고 advantage 가 잡음이 된다.

### 2-3. 학습 — 신호 대 잡음이 구조적으로 나빴다
- 종단 success 보너스 W=1.0 은 베르누이(p≈.75, **std .43**)인데 마진 효과 크기는 .012~.06 이다.
  성공 분산이 모든 grip 스텝의 advantage 를 지배하고, 성공 여부는 대부분 Δ 가 아니라 장면이 정한다.
- **물체·장면별 baseline 이 없다.** 33 물체 × replica 를 한 배치로 섞고 advantage 를 전역 정규화 →
  "어떤 물체를 뽑았나"의 분산이 "Δ 가 뭘 했나"를 덮는다.
- 탐색이 **스텝별 i.i.d. 가우시안**(σ≈.37 pre-tanh). 최적화 대상은 "유지되는 자세"인데
  3 Hz 로 클램프 크기만큼 흔든다. 보고된 포화도 .30~.44 의 상당 부분이 탐색 잡음으로 설명된다.

### 2-4. 그래서 null 의 해석
> **"residual 로는 안 된다"가 아니다.** 정확히는 — 접촉 배치를 바꾸지 못하는 행동 공간에서,
> 형상도 촉각도 보지 못하는 관측으로, 성공 분산이 지배하는 advantage 로 학습했다.
> **세 축이 전부 어긋나 있었다.**

## 3. 방법의 형태 — 왜 "지각 기반 제어" 인가

M3 + M7 을 붙이면 해의 형태가 강제된다.

- 여유는 **실재**한다 (+0.71 카운트, 재생 검증)
- 그러나 **장면이 바뀌면 전이되지 않는다** (≈0)
- 그리고 **방향 없는 탐색으로는 못 찾는다** (무작위 8개가 0% 회수)

> **장면마다 다시 풀어야 하고, 풀려면 장면을 봐야 한다.**
> 지각은 제어의 선택사항이 아니라 **유일하게 가능한 해의 형태**다.

### 3-1. 이번 critic 실험이 선 자리 — 재순위(steering)는 절반만 맞았다
얼린 teacher + 학습된 검증기 + best-of-K 재순위는 VLA steering(V-GPS 계열)과 같은 메커니즘이다.
검증기로서는 **작동했다** — 무작위 대비 +0.093 (CI [+.061,+.126]), 효율 η=.52, lift SR 도 +0.039.
그러나 **후보 풀에 teacher 를 넘는 것이 없으면 완벽한 검증기도 소용없다.**
→ **재순위가 아니라 탐색·최적화로 가야 한다.**

### 3-2. 촉각의 자리 — 계획기가 아니라 검증기
시점으로 갈린다.

| 시점 | 손이 물체를 가리는가 | 쓸 수 있는 것 |
|---|---|---|
| t=0 계획 | **아니다** (손이 떨어져 있다) | 비전/기하 |
| 접근~폐합 이후 | **그렇다** (접촉면을 손이 가린다) | **촉각** — 가려진 바로 그 지점을 직접 샘플링 |

촉각은 t=0 에 쓸 정보가 없다 (`contact_collection=1` 로 켜도 grip 진입 시 접촉률 **24.6%**).
촉각의 역할은 **"이 파지가 예상대로 버틸 구성인가"를 물리 프로브 없이 확인**하는 것이고,
그것이 실제 로봇에서 6방향 외력 테스트를 대신할 유일한 수단이다.

### 3-3. 수정의 단위 — "조금 고치기"는 증거상 불가
grip 중 ±1 cm 미세수정의 마진 가동범위 전체가 0.012 이고, 행동 서명은 세 번 모두
"원뿔은 회전할 뿐 커지지 않는다"였다. **불안정을 감지해도 그 자리에서 고칠 수 없다.**
수정은 **중단·재계획** 수준이어야 하며, 재계획은 다시 지각으로 돌아간다.

## 4. 로드맵 S1–S4

각 단계는 실행 전에 `EXP_*.md` 로 사전등록한다 ([`PROTOCOL.md`](PROTOCOL.md) §5).

### S1. critic 을 목적함수로 계획을 직접 최적화 ★ 전체 게이트
- 입력 = 특권 완전 점군 (가림 없음). 출력 = 12-D 계획. 탐색 = critic 위 gradient/CEM, **물리 호출 0회**
- lift 붕괴를 막기 위해 **lift 예측기를 같이 학습해 제약**을 건다 (σ≥0.35 에서 lift SR .14 로 붕괴)
- ★ **반드시 독립 재생으로 검증** — critic 위에서만 좋은 해를 거른다 (CEM max-selection bias 전례)
- 기준선 teacher **2.997**, 상한 고정 장면 오라클 **3.71**
- **왜 먼저인가**: 특권 점군을 다 주고도 teacher 를 못 넘으면, 가림·촉각 작업은 얹을 토대가 없다
- **진짜 위험**: ρ=.457 짜리 안내자로 400회 물리탐색이 찾은 해를 0회로 찾아야 한다.
  재생에서 무너지면 문제는 탐색이 아니라 **critic 의 정확도**이고, S2/S3 이 먼저가 된다
- 비용: 기존 46,425 샘플로 학습·탐색은 즉시. GPU 는 검증 재생에만

### S2. 촉각을 켜고 예측력을 잰다
- `task.sim.physx.contact_collection=1`, **특징 포착 시점을 폐합 이후로** 이동
- 변형: 기하 단독 / 촉각 단독 / 촉각+고유수용 / 전부. 지표는 같은 라벨의 홀드아웃 ρ
- 핵심 질문: 손끝 5 + 손바닥 1 의 **net force 6×3 뿐**(taxel 없음)으로 점군 256점을 대체할 수 있는가.
  공간 해상도가 2 decade 부족하므로 **시간축(폐합 과정의 접촉 시퀀스)이 그것을 대신하는가**가 관건
- 여기서 실패하면 taxel 있는 손 또는 다른 센서로 가야 한다 (우산 `references/3d_vitac`·`vitacformer`)

### S3. 가림 모델링 + 증류
- 카메라 시점에서 **손에 가려진 점군**을 만든다 (이 라인의 실험 비용 대부분이 여기 있다)
- S1 의 특권 critic → (부분 점군 + 촉각) student 로 증류. 게이트는 ρ(student)/ρ(teacher)

### S4. 닫힌 고리
- student 가 낮은 안정성을 예측 → **중단·재계획** → 끝단 지표(6방향 카운트 · lift SR)로 평가
- 비교 대상은 teacher 단독과 **같은 횟수만큼 무작위 재시도**하는 대조군

## 5. 규율 (전례에서 얻은 것, 어기면 또 당한다)

1. **판정 임계는 수치 보기 전에 고정**한다. 실험 조건은 바꿔도 되고, 임계는 못 바꾼다
2. **게이트는 그 행동 공간에서 오라클이 도달 가능한 범위를 먼저 재고 정한다** — 아니면 null 이
   "효과 없음"인지 "검정력 없음"인지 구분되지 않는다 (1차 정정의 교훈)
3. **best-of-N 탐색의 보고값은 상한이 아니다.** 독립 재생으로 검증하지 않은 오라클 수치를
   게이트 기준으로 쓰지 마라 (2차 정정의 교훈)
4. **개입 효과는 같은 코드 경로의 무개입 대조군과 비교**한다 (가짜 양성 전례)
5. **★ 남의 코드의 관측 채널은 실제로 0 이 아닌지 먼저 확인한다.** 상수 0 인 입력 차원은 학습을
   조용히 무력화하고 null 의 원인을 "모델"로 오진하게 만든다 (계측기 결함 #7)
6. 감시 루프에서 `pgrep -f <스크립트명>` 금지 — 같은 문자열을 담은 감시 셸 자신을 매칭해 교착한다

## 6. 아직 모르는 것
- 해석적 GWS(ε-metric / Q1) 대비 학습 critic 의 우열 — "학습이 필요했는가"는 미판정
- 파지가 완전히 폐합된 뒤의 상태로 재면 ρ 가 어떻게 되는가 (지금은 grip 진입 첫 스텝)
- 토크·모멘트 저항 (force 3축만 측정). 평가 홀드아웃 축으로 남겨 둔다
- 다른 손(Shadow/Allegro 는 등방적·마진 2배)에서 같은 결론이 서는가
