- 편향 상한(.427)과 opt(.208)의 큰 차이는 2회 측정의 잡음 폭을 보여준다 — 선택과 평가를 분리하지 않으면 +.25 의 가짜 이득이 나온다.

1. **이득이 난 유일한 조합은 "PRE 가 plan 차이를 읽는 손(Inspire, plan 기여 +.06)"이다.** Shadow 는 예측은 잘 하지만 장면 분산만 읽고 계획 분산을 못 읽어 최적화할 신호가 없다. Allegro 는 예측기 자체가 약하다.
2. 풀 여유(oracle8 갭)는 이득을 예측하지 못한다. Inspire 는 여유 0 인데 이득이 났고(CEM 이 풀 밖으로), Allegro 는 여유가 커도 못 잡았다.
   → **재순위 상한(oracle-of-N)은 탐색 방법의 상한이 아니다.** 선행 RESULTS_CRITIC §3 의 "병목 = 후보 풀" 진단은 재순위에만 맞았다.
3. 형상 일반화는 세 손 모두 없다. 학습 물체 25종으로는 새 형상의 계획 개선을 못 배운다. 다음 실험의 한 축.
4. 촉각: 유지 구간에서는 형성 구간보다 값어치가 있다 (Shadow 단독 .79 = 점군 .78; Allegro 손 위에 +.013; Inspire +.00). 손 상태와 절반 이상 겹친다.
