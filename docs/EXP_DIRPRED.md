## 3. 모델 (동결)
- 입력 변형: **P** = 점군 단독 (PointNet 64-128-128, 128점) · **PT** = 점군 + 촉각(cf 3·n_cf, palm 좌표계) ·
  **T** = 촉각 단독 · **P-occ / PT-occ** = 가린 점군.
- 출력: 6 로짓, BCE (라벨 = 3회 평균 확률). Adam 1e-3, wd 1e-5, early stop patience 10, ≤60 epoch.
- 불확실성: **앙상블 5** (seed 0~4), 예측 = 평균, 불확실성 = 6방향 확률의 표준편차 평균.
- 가림 합성: palm 좌표계에서 무작위 단위벡터 v 를 뽑아 `(p−c)·v > 0` 인 점을 제거(c = 점군 중심), 남은 점을
  복제 패딩해 128점. 학습 시 50% 표본에 적용, 평가는 가림/비가림 분리.
- 분할: 물체 홀드아웃 `obj % 4 == 3` (EXP_CRITIC §4 승계), val = train 장면의 20%.
- `nwin == 0` 후보 제외. Part B 에서 `capK == 0`(K 스텝 전에 grip 이 끝난 후보) 은 **K 분석에서만** 제외하고 비율 병기.

## 4. ★ 게이트 (수치 보기 전 고정)

**퇴화 축 규칙**: 홀드아웃에서 양성 비율이 **< 0.05 또는 > 0.95** 인 축은 AUC 가 정의되지 않으므로
판정에서 제외하고 "퇴화" 로 표기한다 (Inspire −x 가 예상 대상). 손별로 따로 판정한다.

| 게이트 | 묻는 것 | 기준 |
|---|---|---|
| **A1** | 방향별로 예측되는가 (P, 비가림) | 홀드아웃 물체에서 비퇴화 축 중 **≥ 2/3 이 AUC ≥ 0.65** |
| **A2** | 불확실성이 정보인가 | 앙상블 std 상위 25% 표본의 \|오차\| ≥ 하위 25% 의 **1.3배** |
| **A3** | 부분 관측에 반응하는가 | 가린 표본의 평균 std ≥ 비가림의 **1.2배** |
| **B0** | 계측기 위생 (Part B 착수 조건) | K 포착 시점 접촉률(cf 노름 > 0.05 N 인 센서 ≥ 1) **≥ 0.7** · 슬롯 0 카운트가 같은 손의 선행값 ±0.3 |
| **B1** | 촉각이 기여하는가 | `AUC(PT) − AUC(P)` 비퇴화 축 평균 **≥ +0.05**, 또는 가림 조건에서 **≥ +0.10** |

- A1~A3 는 **Part A(Inspire 기존)** 와 **Part B(각 손)** 에 각각 적용한다. A3 는 P 모델로 판정.
- B1 은 **K 포착** 특징으로 판정한다. 첫 스텝 포착은 병기만 (P9 확인용).
- **F-기준**: A1 불통과 = "방향별 응답은 관측에서 예측되지 않는다" → 아이디어의 앞 절 기각.
  B0 불통과 = Part B 무효 (계측기), 결과를 판정에 쓰지 않는다.

## 7. 이 실험이 말하지 **않는** 것
- 예측기로 **더 잘 잡는가** (행동 이득). 선행 G-C 가 후보 풀 문제로 불통과했고, 여기서 재지 않는다.
- 토크 축. 하네스가 힘 3축만.
- 실물. 촉각은 시뮬 net contact force (taxel 아님).
- "속도" 라벨. 이진 버팀(20 mm)만. 연속 변위는 이번에 덤프하지 않는다.
- 신뢰도 → 능동 탐색 행동. 예측기까지.
