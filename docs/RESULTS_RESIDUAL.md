## 4. ⚠ 가짜 양성을 하나 잡았다 — Δ=0 대조군이 없었으면 속았다

첫 평가에서는 residual 이 M 평균을 **0.424 → 0.524 (+0.10)**, 최약/최강 이방성을 **79× → 14×**
로 개선한 것처럼 보였다. 전부 **평가 코드 경로 차이**였다:

> 내 eval 루프가 `reset_idx` 를 한 번 더 부르는 바람에 `_br_round` 가 밀렸고,
> 외력이 걸리는 시점(grip 진입 후 offset)이 **baseline 0–9 스텝 → 1–10 스텝**으로 이동했다.
> 마진은 grip 이 진행될수록 커지므로([`RESULTS_BRANCH.md`](RESULTS_BRANCH.md) §3-5) 그만큼 부풀었다.

조치: ① 에피소드가 실제로 돈 경우에만 라운드를 세도록 통일 ② 분석의 offset 을 유효 라운드
최소값 기준 상대값으로 ③ **같은 코드 경로의 Δ=0 대조군을 기준선으로 채택**.
교정 후 Δ=0 대조군은 baseline 을 재현한다 (SR 0.755 vs 0.758, M 0.456 vs 0.424/0.446 = seed 폭 내).

★ **교훈**: 개입의 효과는 **같은 코드 경로의 무개입 대조군**과 비교해야 한다.
다른 경로로 만든 baseline 숫자와 비교하면 경로 차이가 효과로 둔갑한다.

## 5. 왜 안 되는가 — 다음 실험으로 이어지는 해석

[`RESULTS_BRANCH.md`](RESULTS_BRANCH.md) §3-1 이 잰 실패 기제는 **엄지 반대쪽(−x)에 받칠 것이
아무것도 없다**는 기하 문제다. grip 이 시작된 시점에는 손이 이미 물체에 붙어 손가락이 닫히는
중이므로, 관절을 ±0.15 움직여 **더 세게 쥘 수는 있어도 엄지를 반대편으로 옮길 수는 없다.**

> 가설: **마진은 grip 중에 고칠 수 있는 양이 아니라 t=0 파지 자세 결정에서 정해진다.**

→ 이를 시험하는 변형을 돌리고 있다: **`plan_min` / `plan_sum`** — teacher 의 t=0 12-D edit 에
residual 을 얹고 같은 마진 보상으로 학습 (1-step MDP). 결과는 §6 에 추가한다.
