## 0. 한 줄

> **① 들고 있는 상태(t₀)에서 방향별 외력 응답이 관측으로 예측되는가. ② 실행 전(t=0) 장면+계획만으로도 예측되는가.
> ③ ②의 예측기로 계획을 최적화하면 물리 재생에서 teacher 보다 다방향 자세 유지가 실제로 오르는가.**
> ①은 DIRPRED 를 사용자 그림(hold 상태)으로 옮긴 것, ③이 아이디어 뒷 절(행동 이득)의 첫 판정이다.

## 1. 라벨 (hub posthold 장치 그대로, EXP_POSTLIFT §1)

t₀ = 원 성공조건(flag ∧ Δz>0.1) 최초 참 + 무교란 1 s(HOLD=3 스텝). t_lift 에 main→그림자 재복제.
외력 = 물체 COM, **t₀ palm 좌표계 ±x ±y ±z 고정**, α·m·g, 0.1 s 램프 → 1 s 유지 → 1 s 관찰. **α = 8 (ours_S 에서 ≈ 2.4 N)**.
- **Y_hold** = 관찰 종료 e_p ≤ 5 cm ∧ Δz > 5 cm · **Y_pose** = Y_hold ∧ 창 전체 max e_p ≤ 2 cm ∧ max e_R ≤ 15°
- **1차 라벨 = Y_pose 6방향** (사용자 질문 "외력에 움직임 여부" = 자세 유지). Y_hold 는 병기.
- 후보 = teacher 12-D edit + σ∈{0.05,0.10,0.20} 섭동, 물체당 R=8 (슬롯 0 = teacher). 같은 (장면·후보) **2회 독립 반복 (A/B)**.
- g0(t₀ 도달) = 0 인 후보는 라벨 미정의 → 제외하고 비율 병기. 6방향 창 미완료(done<6)도 제외.
- 손별 reset DOF 잡음 = 원저자 규약 (Inspire 0.2 · Shadow 0) — hub 의 posthold 기준선과 맞춘다. DIRPRED(전 손 0.2)와 다름을 명기.

## 3. 특징·모델 (동결)
- **hold 상태 특징** (t₀ 도달 스텝 직후): palm 점군 128점 · 촉각(cf) · 손 상태(관절+손끝) — 변형 P / PH / PHT (DIRPRED 와 동일 구조, 앙상블 5).
- **실행 전 특징** (t=0): 월드 점군(물체 중심 기준) 128점 · 물체 자세 q · teacher edit 12-D · 후보 plan 12-D → 변형 **PRE** (PointNet + MLP, 6 로짓 + **g0 로짓 1**).
- 분할 = 물체 홀드아웃 `obj % 4 == 3`, val = train 장면 20%. 퇴화 축 규칙 = DIRPRED 와 동일 (양성 비율 <.05 또는 >.95 제외).

## 4. 계획 최적화 → 물리 재생 (행동 이득)
- 홀드아웃 물체 × 홀드아웃 장면(별도 seed 로 새 장면 S_test 개)에서, **PRE 예측기의 앙상블 평균**을 목적함수로
  12-D 를 CEM(64 후보 × 8세대, σ₀=0.1, teacher 중심, [-1,1] 클램프, **teacher ±0.3 신뢰영역**)으로 최적화.
  목적 = `min_d p_pose(d)` (ε 대응) + λ·g0 제약 (`p_g0 ≥ 0.5` 미달 후보는 폐기). 물리 호출 0.
- 재생 = 같은 장면(p0 고정)에서 4가지 계획을 **같은 하네스·2회 반복**으로 측정: `teacher` · `random`(σ=0.1 섭동 1개) ·
  **`opt`**(PRE 최적화) · `oracle8`(무작위 8후보를 A 로 골라 B 로 읽음 — 무편향 선택 상한).
- 지표 = **R_all_pose** (6방향 Y_pose 전부 통과, 장면·물체 단위 평균) · R_mean_pose · g0 · 방향별 Y_pose.

## 5. ★ 게이트 (수치 보기 전 고정)
| 게이트 | 묻는 것 | 기준 |
|---|---|---|
| **H0** | 계측기 위생 | control(외력 0) Y_hold ≥ 0.97 (hub 기준) · g0 도달률 병기 · 슬롯 0 lift SR 이 hub/failmap 값 ±0.05 (Inspire .76, Shadow .60) |
| **H1** | hold 상태에서 방향별 예측 | P 모델, 비퇴화 축 ≥ 2/3 에서 AUC ≥ 0.65 (Y_pose) |
| **H2** | 실행 전 예측 | PRE 모델, 비퇴화 축 ≥ 2/3 에서 AUC ≥ **0.60**, g0 AUC ≥ 0.65 |
| **H3** | ★ 행동 이득 | 재생에서 `opt − teacher` 의 **R_all_pose ≥ +0.10**, 장면 단위 페어드 부트스트랩 95% CI 가 0 제외, **g0(opt) ≥ g0(teacher) − 0.05** |
| H3′ | 선택 상한 대비 | η = (opt − teacher)/(oracle8 − teacher) 병기 (판정 아님). oracle8 ≤ teacher 이면 "후보 풀 문제 재현"으로 기록 |

- H1 불통과 → hold 상태에서도 관측으로 안 읽힌다 = DIRPRED 결론이 형성 구간 특유였음. ③ 진행하되 결과 해석에 명기.
- H2 불통과 → ③을 **하지 않는다** (물리 없이 최적화할 근거가 없다). 대신 oracle8 vs teacher 만 재생해 후보 풀에 여유가 있는지 보고.
- H3 불통과 → 행동 이득 없음으로 기록. 원인 분해: (a) PRE 가 최적화 방향에서 틀림(재생 p_pose 예측 vs 실측 상관) (b) 12-D 안에 여유 없음(oracle8 ≤ teacher).
- +0.10 근거: hub 결손 규모(Shadow 자세 R_all 0.55, Inspire 0.73~0.85)에서 임상적으로 의미 있는 최소 변화. 선행 G-C 의 "오라클 갭 25%" 관례는 이번엔 갭을 모르므로 쓰지 않는다.

## 6. 병기 필수
방향별 Y_pose/Y_hold 6개 · 라벨 재현성 corr(A,B) · 첫 DIRPRED 와의 대비(형성 vs hold 에서 점군 AUC) · 촉각/손 상태 이득 · PRE 의 `plan` 제거 절제(장면만으로 얼마나 맞히나 = 후보 간 분산이 있는가) · CEM 이 teacher 에서 얼마나 움직였나(‖Δ‖ 분포).
