# EXP — 파지 후(post-lift) 다방향 안정성 · 사전등록 (결정 1)

> ★ **판정 규칙은 측정 전에 고정한다.** 이 문서 §4 는 첫 수치를 보기 전에 작성됐다 (2026-09-29).
> 측정 정의 = [`Stability_Metrics.md`](Stability_Metrics.md) §2~§5 (지표 A·C). 장치 = 분기 하니스(`gs_branch.py`, replicate-once).

## 0. 무엇을 결정하는가

universal 정책의 한계를 **A. 형성 단계의 불완전 닫힘**으로 정의할지, **B. 들어올린 뒤의 다방향 안정성**으로 정의할지 결정한다.
Stage 0 D3 는 "들어올린 뒤는 무게 20배까지 버틴다"고 했지만, 그 측정은 **에피소드마다 무작위 수평 1방향**이었다.
손바닥 6방향 전부 통과(R_all), 상대 자세 오차는 재지 않았다. → 이 문서가 그 공백을 잰다.

**판정 (per 분기)**
- 물체 유지 Y_hold = 관찰 종료 시 손–물체 상대 위치 편차 e_p ≤ 5 cm ∧ Δz > 5 cm

- R_d · R_mean · R_all(같은 t₀ 상태에서 분기한 6방향 전부 통과) — 물체별 평균 후 macro 평균, R_all 은 물체 cluster bootstrap 95% CI

## 2. 게이트 (측정 유효성)

- control 그룹(외력 0) Y_hold ≥ 0.97, control e_p(관찰 종료) 중앙값 ≤ 2 mm. 불통과 셀은 무효.
- 창 미완료(에피소드가 먼저 끝남) 비율 보고. 10 % 초과면 τ 를 늘려 재측정.

## 4. ★ 판정 규칙 (측정 전 고정)

| 관측 (seed 42·43 둘 다) | 판정 |
|---|---|
| 어느 한 손이라도 **R_all(α=8) < 0.80** 또는 **자세유지 R_all(α=4) < 0.80** | **B 결손 실재** → 문제를 B(또는 A→B 인과, C)로 정의 |
| 세 손 모두 **R_all(α=8) ≥ 0.92** 이고 **자세유지 R_all(α=4) ≥ 0.90** | **B 결손 없음** → 문제를 A(형성)로 정의 |
| 그 외 | **유보** → `ours_M` 추가 · 토크 시험 추가 후 재판정 |

근거: 0.80 ≈ BODex 6방향 전부 통과 기준에서 최선 방법의 성공률(79.9 %), 0.92 ≈ RobustDexGrasp 2.5 N 시험 성공률(92.0 %).
두 수치 모두 다른 환경의 값이라 **기준선의 규모**로만 빌려온다.

★ 병기 필수: 방향별 R_d 6개(이방성), G(초기 파지 성공률), max e_p·e_R 중앙값, 원 DemoGrasp SR.
