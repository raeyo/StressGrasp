## 2. 원 판정 (τ₀) — 우리가 바꾸지 않는 기준선

```
successes = (object_delta_z > 0.1) AND (fingertips_dist <= 0.12*n_fingers OR palm_dist <= 0.15)
SR(τ)     = τ 스텝 에피소드에서 t = τ−2 의 successes 평균
τ₀        = 50 steps (= 16.7 s)      # DemoGrasp 기본 episodeLength
```

★ 우리는 **성공 판정식을 고치지 않는다.** `τ`(판정 시점)와 **물리 조건**만 바꾼다. 그래야 낙폭이
"우리가 기준을 엄하게 해서"가 아니라 **같은 기준을 더 늦게/더 무겁게 적용했을 때** 나온 것이 된다.

## 4. 평가 세트 · 시행 수

| 세트 | 물체 수 | num_envs | 물체당 시행 |
|---|---|---|---|
| `ours_S` (3–6 cm) | 33 | 66 | 20 (10 round × 2 env) |

| `ours_L` (10–15 cm) | 34 | 68 | 20 |

★ **`num_envs ≥ 물체 수` 필수** — env 배정이 round-robin 이라 작으면 앞의 n 개만 평가된다.
★ seed 2회 반복으로 **반복 폭**을 먼저 실측한다. 반복 폭이 판정 임계의 근거다.

## 5. ★ 판정 규칙 (측정 전 고정)

**기본 통계**: 물체 단위 paired 비교 (n = 33/33/34/100). seed-std 로 판정하지 않는다.

| 관측 | 판정 |
|---|---|
| 전 축 최대 낙폭 **ΔSR < 0.05** | **F1 발동 → 문제 없음. 프로젝트 종료.** |
| 0.05 ≤ ΔSR < 0.10 | **판정 유보** — 시행 수를 늘려 재측정 |
| **ΔSR ≥ 0.10** 이고 paired p < 0.01 | **문제 실재** — 다음 단계 진행 |

추가 게이트:
- **F2**: 낙폭 에피소드의 물체 속도/관통이 비물리적이면(발산) 해당 셀 무효.
- **F3**: lift SR vs retention SR 의 **Spearman ρ > 0.9** (정책×세트 셀 기준) → 새 지표 불필요.
- **F4**: open-loop 와 closed-loop 정책의 낙폭 차이가 반복 폭 안이면 → 제어 구조 무관.

## 6. 기록 규칙

- 원시 로그는 **레포 밖** (`runs/`, gitignore). 판독 근거가 되는 요약만 `results/` 에 커밋.
- 셀마다 `{policy, objset, tau, mass, force, seed}` 를 파일명·JSON 에 남긴다.
- 조건별 결과를 같은 파일에 덮어쓰지 않는다.
- **머신 절대값 교차 비교 금지** (이 프로젝트 수치는 kimm-h200 기준).

## 7. 먼저 확인할 위생 항목 (측정 전)

1. τ₀=50 에서 **기존 재현값이 복원되는가** (ours_S ≈ 0.76 / M ≈ 0.90 / L ≈ 0.92). 안 되면 파이프라인 문제.
2. seed 2회 **반복 폭** 실측 → §5 임계값이 반복 폭보다 충분히 큰지 확인.
3. τ 를 늘렸을 때 **레퍼런스 궤적이 잘리지 않는지** 확인 (`reaching_plan` 은 max_episode_length 로 clamp 됨 → τ 증가는 안전, τ 감소는 금지).
