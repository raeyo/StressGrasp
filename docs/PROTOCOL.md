## 2. 원 성공 판정식 — 우리가 **고치지 않는** 기준선

```
flag      = (fingertips_dist <= 0.12*n_fingers) OR (palm_dist <= 0.15)
lifted    = object_delta_z > 0.1
successes = lifted AND flag                       # 매 스텝 계산
SR(τ)     = τ 스텝 에피소드에서 t = τ−2 의 successes 평균
τ₀        = 50 steps (= 16.7 s)                   # DemoGrasp 기본 episodeLength
grip      = flag AND (NOT lifted)                 # 형성 구간 = 우리 주 측정 구간
```
★ **성공 판정식을 고치지 않는다.** τ(판정 시점)와 **물리 조건**만 바꾼다.
★ 시점 정의에 **성공 판정식이 쓰는 값을 그대로** 쓴다 — 별도 기준을 만들면 "언제부터 파지인가"가 어긋난다.

## 3. ★ 안정성 라벨 정의 (고정 — 모든 실험이 이것을 쓴다)

| 항목 | 값 | 왜 |
|---|---|---|
| 좌표계 | **palm** | world 축으로 재면 마진 **30% 과대** ([`FACTS.md`](FACTS.md) A1) |
| 방향 | **±x ±y ±z (6)** | 토크·모멘트는 넣지 않는다 (현 범위 밖) |
| 크기 | **α · m · g**, 기본 **α=1 g = 303 mN** | 질량 정규화(물체별 난이도 왜곡 방지). α=1 에서 네 방향이 .46~.60 = **베르누이 분산 최대** |
| 판정 | **이진 hold** `1[d_i < θ]`, **θ = 20 mm** | 변위 분포가 held ~1–4 mm vs lost ~1000 mm 로 극단이라 10~100 mm 어디든 같은 값 |
| **분기 지평** | **H = 5 env-step (1.67 s)** | H=1 은 게이트 미달(0.230). **외력 중엔 안 움직이고 나중에 놓친다** (A5·D2) |
| dose | **1 env-step 고정** | 고정 안 하면 시점 간 비교 불가 (**P2**) |
| 라벨 값 | **grip 구간 창 평균 카운트 (0~6)** | 첫 window 단독은 corr .165 로 **부적격** (B1) |
| 반복 | **3회 독립 측정** | 1회 ICC .554 → 3회 평균 신뢰도 **.789** (예측 상한 ρ≤.745) |

★ **연속 보상 `τ/(τ+d)` 는 쓰지 마라** — 최약축이 거의 항상 파국이라 상수에 붙고 기울기가 0 이 된다.
**이진은 기댓값이 곧 생존확률**이라 policy gradient 가 그것을 직접 추정한다.

## 3-1. ★ 파지 후(post-lift) 프로토콜 — 결정 1 이 쓴 것

지표 정의는 [`Stability_Metrics.md`](Stability_Metrics.md) §2~§5 (지표 A·C)가 정본.

| 항목 | 값 |
|---|---|
| **시작 상태 t₀** | 원 성공조건(`flag ∧ Δz>0.1`)이 처음 참이 된 뒤 **1 s(3 env-step) 무교란 유지**를 통과한 시점. 유지 실패 = **초기 파지 실패**(G=0) |
| 외력 | 물체 **COM**, palm ±x ±y ±z. ★ **방향은 t₀ 의 palm 자세로 고정** (follower load 아님) |
| 파형 | **0.1 s 선형 증가 → 1 s 유지 → 제거 후 1 s 관찰** |
| 크기 | α·m·g, α ∈ {0.5, 1, 2, 4, 8}. `ours_S` 에서 **α=8 ≈ 2.4 N** (RobustDexGrasp 2.5 N 시험과 같은 규모) |
| **물체 유지** `Y_hold` | 관찰 종료 시 손–물체 상대 위치 편차 `e_p ≤ 5 cm` ∧ `Δz > 5 cm` |
| **자세 유지** `Y_pose` | `Y_hold` ∧ 창 전체 `max e_p ≤ 2 cm` ∧ `max e_R ≤ 15°` |
| 집계 | `R_d`(방향별) · `R_mean` · **`R_all`**(같은 t₀ 에서 분기한 **6방향 전부 통과**). **물체별 평균 후 macro 평균**, `R_all` 은 물체 **cluster bootstrap 95% CI** |
| 에피소드 길이 | 80 (창 완료 보장. 판정 시점 연장은 SR 불변) |

**유효성 게이트**: control(외력 0) `Y_hold ≥ 0.97` **and** control `e_p`(종료) 중앙값 `≤ 2 mm`.
불통과 셀은 **무효**. 창 미완료 비율 보고 — 10% 초과면 τ 를 늘려 재측정.
⚠ **잡음 바닥**: control 불일치 ~1% 가 6방향 곱에 쌓여 `R_all` 에 **~6% 바닥**이 있다.

**판정선의 출처** (다른 환경의 값이라 **규모로만** 빌려온다):
`0.80` ≈ BODex 6방향 전부 통과에서 최선 방법(79.9%) · `0.92` ≈ RobustDexGrasp 2.5 N 시험(92.0%).

★ **병기 필수**: 방향별 `R_d` 6개(이방성) · `G`(초기 파지 성공률) · `max e_p`·`e_R` 중앙값 · 원 DemoGrasp SR.

## 4. 하네스 — 그림자 env 그룹

DemoGrasp 은 env `i` 에 물체 `i % n_obj` 를 배정한다(`tasks/grasp.py:399`) → env `{j, j+n_obj, …}` 가
**같은 물체**다. 이 세로줄을 그룹으로 쓴다.

```
num_envs = n_obj × replicas × G          G = 2 + 6·|alpha|
g=0 main (정책 구동)  ·  g=1 control (복제, 외력 0)  ·  g≥2 probe (복제 + (dir,α))
```
- 변위는 **main 대비**로 잰다 → 중력과 정상 파지운동이 자동 상쇄된다.
  **control 의 변위 = 순수 복원 오차** = 충실도 게이트.
- ★ **Δ(개입)는 main 의 관측으로 한 번 계산해 그룹 전체에 같은 값**을 쓴다 — 그림자가 같은
  컨트롤러로 굴러야 마진이 "상태의 속성"으로 남는다.
- **복사해야 하는 상태** (빠지면 브랜치가 거짓말한다): 물체 root state 13종
  (**env origin 을 더하지 마라** — env-local 이다, **P6**) · robot dof state ·
  **`prev_targets`·`cur_targets`**(PD 목표) · `progress_buf` ·
  (reset 시 1회) `table_heights` + table root state ·
  ★ **`plan_anchor_pos`**(hub 의 수정본 포크에만 있다 — 없으면 `getattr` 로 건너뛴다, **P17**)
- ★ **재복제 시점**: t₀ 에서 바로 텔레포트하면 PhysX 접촉 캐시 충격으로 위치 불변인데 **15~176° 회전**한다.
  **t_lift 로 앞당기고** 유지 구간 동안 안정화시킨 뒤 기준 자세를 읽는다 (**P18**)
- ★ 외력은 **`simulate()` 직전마다 재적용** — `apply_rigid_body_force_tensors` 는 다음 1회에만 걸린다 (P1)

| 모드 | 복제 시점 | 읽는 값 | 용도 |
|---|---|---|---|
| **replicate-once** | 리셋 직후 1회 | 에피소드 **최종 생존** (원 판정식 그대로) | 마진 M(s) |
| **per-step (H)** | grip 중 **H 스텝마다** | 물체 변위 | 학습 보상 라벨 |

### 충실도 게이트 (수치 보기 전 고정, 실제로 통과함)
| 모드 | 지표 | 임계 | 실측 |
|---|---|---|---|
| replicate-once | main SR vs control SR · per-object 불일치 | — | .755/.758 · **4.9~7.0%** ✅ |
| per-step | 복원오차 / α=1 신호 | **< 0.20** | H=1 **0.230** ⚠ → H=5 **0.104** ✅ |
| 공통 | control 변위 < 물체 지름의 10% | | ✅ |

## 5. ★ 판정 규율 (어기면 판정이 무효다)

1. **판정 임계는 수치 보기 전에 고정한다.** **실험 조건은 바꿔도 되고 임계는 못 바꾼다.**
   게이트 실패는 그대로 기록한다.
2. **게이트는 그 행동 공간에서 오라클이 도달 가능한 범위를 먼저 재고(sweep) 정한다** —
   아니면 null 이 "효과 없음"인지 "**검정력 없음**"인지 구분되지 않는다 (P4).
3. **best-of-N / CEM 의 보고값은 상한이 아니다.** **독립 재생으로 검증**하지 않은 오라클 수치를
   게이트 기준으로 쓰지 마라 (P3).
4. **개입 효과는 같은 코드 경로의 무개입(Δ=0) 대조군**과 비교한다 (P5).
5. **선택과 평가를 분리한다** — repeat A 로 고르고 repeat B 로 읽는다 (max-selection bias 차단).
6. 기본 통계 = **물체 단위 paired** (n=33). seed-std 로 판정하지 않는다.
   seed 반복 폭 실측: SR **0.020** · M 평균 **0.010~0.019**.
7. ⚠ **M 과 최종 성공의 상관(AUC)을 예측력 근거로 인용하지 마라** — 순환적이다 (D4).

### 표준 게이트 형태 (개입 실험)
| 관문 | 기준 |
|---|---|
| **G1 비퇴화** (선결) | lift SR ≥ Δ=0 대조군 − 0.05. 마진이 올라도 **불통과면 기각**(보상 해킹) |
| **G2 마진** | M 평균이 대조군 대비 **+(오라클 갭의 25%)** 이상, 그리고 seed 폭의 4배 이상 |
| **G3 최약축** | 최약 방향 생존이 대조군 대비 유의하게 상승 |
| **G4 변형 비교** | 변형 간 차가 seed 폭의 3배 이상이어야 "다르다"고 말한다 |

**병기 필수**: 방향별 생존율 6개 전부 · Δ 포화도(클램프에 붙어 있나) · 학습 드리프트(처음20 vs 마지막20, Δ/SE) · lift SR.

## 7. 재현 파라미터 (선행 실험이 실제로 쓴 값)

| 실험 | 설정 |
|---|---|
| **분기 측정** | `ckpt/inspire.pt` · `ours_S` · α 사다리 {0.125, 0.25, 0.5, 1, 2} · 6방향 · palm · 10 라운드 · seed 42/43 |
| **residual 학습** | `n_obj 33 × replicas 4 = n_main 132`, G=8 → **num_envs 1056** · PPO(GAE λ=.95, γ=.99, clip .2, 4 epoch) · **120 iteration** · grip 스텝만 학습 · Δ 클램프 ±1 cm / ±0.15 (plan 은 ±0.2 → ±0.5) |
| **오라클 CEM** | 물체 자세 고정(`resetDofPosRandomInterval=0`) · 물체별 12-D edit · **R=16 후보 × 25 세대, σ₀=0.35** · **lift 실패 후보는 −1 로 탈락** |
| **critic 데이터** | 2112 env = 물체 33 × 후보 8 × G 8 · 1 에피소드(3회 반복) **≈ 59 s** · 후보 0 = teacher 원본, 나머지 7 은 **σ ∈ {0.05, 0.10, 0.20}** 순환 · 물체 split `obj_id % 4 == 3` → 홀드아웃 |
| **critic 모델** | MLP 256-128 · PointNet 64-128-128 · Adam 1e-3 · wd 1e-5 · early stop patience 10 |
| 12-D 물리 스케일 | 손목 ±5 cm · 손목 RPY ±1.57 rad · grasp qpos ±1 rad |

★ **σ ≥ 0.35 금지** — lift SR 이 .14 로 붕괴한다 (σ=0.6 → .038). 넓게 탐색하려면 **lift 제약을 같이 건다.**
★ `nwin == 0`(grip 미진입) 후보는 분석에서 제외하고 **제외 비율을 병기**한다.

## 8. 기록 규칙

- 원시 로그는 **레포 밖** (`runs/`, gitignore). 판독 근거가 되는 요약만 `results/` 에 커밋.
- 셀마다 `{policy, objset, tau, mass, force, seed}` 를 파일명·JSON 에 남긴다.
- 조건별 결과를 같은 파일에 덮어쓰지 않는다.
- ★ **머신 절대값 교차 비교 금지.** 결과 파일명에 **워크스페이스 태그**: `results/<실험>__<태그>.md`
  (**P19**). 결정 1 은 **hub(RTX 3080)**, 나머지는 **kimm-h200** 이다.
- ★ 판정 규칙(임계)은 **측정 전에 hub 가 `EXP_*` 문서로 master 에 커밋**하고, 다른 워크스페이스는
  그 커밋 **이후에** 측정을 시작하며 결과 파일에 **기준 커밋 해시**를 적는다 ([`CLAUDE.md`](../CLAUDE.md) §2).
- 무효 처리된 측정은 **삭제하지 않고** `runs/_invalid_*/` 에 **사유서와 함께** 격리한다.

## 9. 착수 전 위생 항목

1. τ₀=50 에서 **기존 재현값이 복원되는가** (ours_S ≈ .762 / M ≈ .895 / L ≈ .935)
2. **접촉 채널이 실제로 0 이 아닌지** 확인 (P7)
3. seed 2회 **반복 폭** 실측 → 임계가 반복 폭보다 충분히 큰지
4. τ 증가는 안전(`reaching_plan` 은 max_episode_length 로 clamp), **τ 감소는 금지**
5. embodiment 별 원저자 `play_policy.sh` 규약을 **그대로** 따른다 (P15)
