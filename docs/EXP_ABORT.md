## 0. 왜

POSTRES 가 "폐합 후 **지속 오프셋**으로 고치기"를 죽였다. 죽지 않은 것은 **시변 행동**, 그중 가장 단순한 형태가
**놓고 다시 잡기**다. 그리고 이것이 촉각의 유일한 자리다 —
**촉각은 폐합 후에 정보를 갖고(Shadow 유지 구간 단독 AUC .79), 행동은 폐합 전에 효과를 갖는다.**
둘을 잇는 다리는 연속 수정이 아니라 **"지금 이 파지를 포기할 것인가"라는 이산 결정** 하나뿐이다.

## 1. 측정

장면마다 물체별 **R=8 후보 계획**(슬롯0 = teacher, 1~7 = σ∈{.05,.10,.20} 섭동 — HOLDPRED 와 동일)을
같은 초기자세에서 굴리고 **A/B 2회** 독립 측정. 각 후보마다 **두 시점**의 특징을 뜬다:

| 시점 | 언제 | 왜 |
|---|---|---|
| **C** (cheap) | grip 진입 + K=5 스텝 — **들기 전** | 여기서 중단하면 **들지도 않는다** = 가장 싼 중단 |
| **L** (late) | t0 = lift + HOLD — **들고 난 뒤** | HOLDPRED H1 이 쓴 시점. 비싸지만 정보가 많다 |

특징 = `priv_obs`(손 관절 · 물체 상대 · 손끝 · **접촉력** · 속도 · 시간) + 손바닥 좌표계 점군 256.
라벨 = posthold **R_all_pose** (g0 ∧ 6방향 done ∧ 6방향 Y_pose). 손 = Shadow 먼저, 그 다음 Inspire.
장면 40 (seed 42), `GS_CC=1`, α=8.

## 2. 순차 정책 시뮬레이션 (물리 재실행 없음)

예측기 `f(특징) → P(R_all_pose=1)` 를 **rep A 라벨**로 학습(홀드아웃 = 물체 `obj%4==3` **과** 장면 후반 절반).
예산 B 회 시도. 후보 순서는 무작위 순열. 각 시도마다 폐합 후 특징을 보고 `f < τ` 면 **중단**하고 다음 후보로,
아니면 **채택**. 결과 = 채택한 후보의 **rep B 라벨**(학습·선택과 평가를 분리 — 함정 #3). 예산 소진 시 마지막 후보.

대조군 셋:
- **teacher 단독** (B=1, 중단 없음)
- **★ 동일비용 무작위 중단** — 학습 정책과 **같은 중단율**로, 특징을 안 보고 무작위 중단 (METHOD §4 S4 가 지정한 대조군)
- **오라클 중단** (참 라벨로 중단 — 상한)

비용 = 평균 시도 횟수. 지표는 **같은 비용에서의** 성공률로 읽는다.

## 3. ★ 판정 (수치 보기 전 고정)

| | 조건 |
|---|---|
| **A0 계측기** | 슬롯0 R_all_pose 가 HOLDPRED teacher ±0.08 (Shadow .346 · Inspire .578) ∧ **C 시점 포착률 ≥ 0.80** ∧ control Y_hold ≥ 0.95 |
| **A1 예측** | C 시점 특징의 홀드아웃 **AUC ≥ 0.65**. 미달이면 중단 결정의 근거가 없다 → 아래를 읽지 않는다 |
| **A2 ★행동** | 예산 **B=2** 에서 (학습 중단) − (동일비용 무작위 중단) ≥ **+0.10** ∧ 95%CI>0 |
| **A3 시점** | C(들기 전) vs L(들기 후) AUC 차. 기록만 — "싼 시점의 대가"를 수치화 |
| **A4 ★촉각** | C 시점에서 **촉각 포함** AUC − **촉각 제외** AUC ≥ **+0.03** 이면 촉각이 중단 결정에 기여한다 |

A2 가 이 실험의 판정이다. A1 통과 + A2 불통과 = "예측은 되는데 행동으로 안 바뀐다" — 선행 critic 재순위와 같은 결말.
