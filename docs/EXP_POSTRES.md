## 0. 무엇을 증명하려는 실험인가

사용자 제안: **"DemoGrasp 궤적은 가이던스로만 주고, 메인은 촉각 기반 안정파지 RL"**.
이 제안을 학습으로 검증하려면 먼저 **그 행동공간에 개선의 여지가 있는지**를 알아야 한다.
[`METHOD.md`](METHOD.md) §3-3 이 이미 말한다 — grip 중 ±1 cm 미세수정의 **마진 가동범위 전체가 0.012**(게이트 +0.10)였고,
행동 서명은 세 번 모두 *"원뿔은 회전할 뿐 커지지 않는다"*였다.

그러나 그 0.012 는 **세 가지 제약 아래에서** 잰 값이다 ([`METHOD.md`](METHOD.md) §2-1):
1. **손목 회전을 한 번도 안 건드렸다** — 주입은 `act[:,0:3]`(EE 위치)과 손 관절뿐. 오라클이 가장 많이 바꾸는 축(.14~.25)이 빠졌다.
   ★ 이번에 코드를 확인한 결과 `arm_controller=pose` 에서 `act[:,0:7]` = **절대 EE pose [위치3, 쿼터니언4]**, `hand_dof_start_idx=7`.
   즉 손목 회전은 `act[:,3:7]` 의 쿼터니언이고, 선행 코드는 이 4차원을 **한 번도 손대지 않았다**. (METHOD §2-1 의 "ref action 3:6" 표기는 축 번호가 아니라 이 사실을 가리킨다.)
2. **클램프가 작았다** — ±1 cm / ±0.15.
3. **형성(grip) 구간 라벨**로 쟀다. 그러나 teacher 를 넘은 유일한 개입(HOLDPRED +.10)과 촉각이 1급 정보가 되는 구간은 **유지(posthold) 구간**이다.

그래서 이 실험은 **학습이 아니라 가동범위 측정**이다. 규율 2("게이트는 오라클 가동범위를 먼저 재고 정한다", 함정 #4) 를 이번에는 **먼저** 지킨다.

## 1. 측정 대상

- **개입 시점**: grip 진입 후 K=5 env-step (= 폐합 이후. 함정 #2 — grip 진입 첫 스텝 접촉률 24.6%). 그 이후 **에피소드 끝까지 상수 Δ 유지**.
  접근·폐합 구간은 teacher 레퍼런스 그대로 = "궤적을 가이던스로" 의 가장 강한 형태(하드 트래킹).
- **계획(12-D plan)은 전 슬롯 동일 = teacher**. 슬롯 간 차이는 **오직 폐합 후 Δ** 다. (HOLDPRED 는 반대로 plan 만 바꿨다.)
- **라벨**: posthold 창 (`GS_BR_OFFSET=posthold`, α=8, HOLD/LOAD/RAMP/RECOVER 기본값), 지표 = **R_all_pose**
  = `g0 ∧ 6방향 done ∧ 6방향 Y_pose 전부 통과` (HOLDPRED `57_gain.py` 와 **같은 정의** — 수치를 직접 붙일 수 있다).
- **손**: Shadow(`shadow_simple`) · Inspire(`default`) 둘 다. 물체 = `ours_bench/ours_S.yaml` 33종. 촉각 켬 (`GS_CC=1`).

## 2. 팔(arm) — 무엇을 비교하나

`act` 레이아웃 = `[EE 위치 3 | EE 쿼터니언 4 | 손 관절 N]`.

| 팔 | Δ 가 닿는 곳 | 의미 |
|---|---|---|
| **ZERO** (슬롯 0) | 없음 | 무개입 대조군. **같은 코드 경로** (규율 4) |
| **OLD** | 위치 `act[:,0:3]` + 손 관절 | **선행 residual 이 쓴 바로 그 공간** (I-6) |
| **ROT** | 쿼터니언 `act[:,3:7]` (world-frame 회전) | **한 번도 안 건드린 축** 단독 |
| **NEW** | 쿼터니언 + 손 관절 | 사용자 제안의 행동공간 |

각 팔 × 2 클램프 레벨 × 4 무작위 후보 = 24, + ZERO = **슬롯 R=25**.

| 레벨 | Δpos | Δrot | Δhand |
|---|---|---|---|
| **L1** (선행 수준) | 0.01 m | 0.05 rad (2.9°) | 0.15 |
| **L2** (확대) | 0.03 m | 0.20 rad (11.5°) | 0.40 |

Δ 는 (장면 × 물체 × 슬롯)마다 한 번 뽑아 **A/B 두 반복에서 동일**하게 쓴다 (A 로 고르고 B 로 읽기 위해).

## 3. 편향 방지 (함정 #3 — best-of-N 보고값은 상한이 아니다)

같은 (장면, 물체, Δ)를 **2회 독립 측정(A/B)**. 팔×레벨마다:
- `best4(A→B)` = A 로 4 후보 중 최선을 고르고 **B 로 읽은** 값 = **무편향 도달값**
- `best4(B→B)` = 편향 상한 (착시의 크기를 같이 보고한다. 판정에 쓰지 않는다)
- 이득 = `best4(A→B) − teacher`, teacher = 슬롯0 의 (A+B)/2
- 95% CI = (장면, 물체) 단위 부트스트랩 4000회

## 4. ★ 판정 (수치 보기 전 고정)

**P0 — 계측기** (전부 통과해야 아래를 읽는다)
| | 조건 |
|---|---|
| P0-a | 슬롯0 R_all_pose (전 물체) 가 HOLDPRED teacher 와 **±0.08** 이내 — Shadow **.346** · Inspire **.578** |
| P0-b | 슬롯0 g0 가 HOLDPRED teacher 와 ±0.08 이내 — Shadow **.590** · Inspire **.755** |
| P0-c | control env(외력 0) Y_hold ≥ **0.95** |
| P0-d | 6방향 done 완료율 ≥ **0.30** (HOLDPRED Shadow .402 · Inspire .622 보다 크게 낮으면 창이 안 닫힌 것) |

**P1 — 주 게이트 · 가동범위** (단위 = 전 물체 (장면,물체); 병기로 홀드아웃 `obj%4==3`)
가장 좋은 팔×레벨의 `best4(A→B) − teacher` 를 `Δ*` 라 할 때, **Δg0 ≥ −0.05** 를 만족하면서:

| Δ* | 판정 | 다음 |
|---|---|---|
| ≥ **+0.10** ∧ CI>0 | **GO** | 폐합 후 촉각 조건부 RL 착수 (게이트는 Δ* 아래에서 정한다) |
| **+0.05 ~ +0.10** ∧ CI>0 | **조건부 GO** | P2 도 통과해야 착수 |
| < +0.05 또는 CI∋0 | **NO-GO** | 폐합 후 미세수정 라인 종료 → 중단·재계획(I-17/S4) 으로 |

**P2 — 진단 · 손목 회전이 원인이었나**
`max(ROT, NEW 의 이득) − max(OLD 의 이득) ≥ **+0.05**` → METHOD §2-1 의 "가장 중요한 축을 안 줬다" 진단을 지지.
(미달이면 진단이 틀렸거나 축이 문제가 아니라는 뜻 — 그대로 기록한다.)

**P3 — 진단 · 클램프가 작았나** (부수, 판정에 안 씀)
같은 팔에서 L2 이득 > L1 이득 인가.
